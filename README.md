\# AIS Smart Parking



Учебный репозиторий проекта \*\*АИС «Умная парковка»\*\*, созданный в рамках практической работы №9 «Настройка .gitignore и прав доступа».



Система предназначена для автоматизации работы парковки и включает модули распознавания государственных номеров автомобилей с помощью OCR и учета свободных парковочных мест по данным датчиков.



\## Структура проекта



```text

AIS\_SmartParking/

├── .gitignore

├── .gitattributes

├── README.md

├── AIS\_SmartParking.sln

├── src/

│   ├── Core/

│   ├── Infrastructure/

│   └── UI/

├── tests/

│   └── SmartParking.Tests/

└── docs/

&#x20;   ├── architecture/

&#x20;   └── openapi/

```



\### Назначение каталогов



\- `src/Core/` — основные модели и бизнес-логика АИС.

\- `src/Infrastructure/` — работа с OCR, датчиками парковочных мест и внешними сервисами.

\- `src/UI/` — пользовательский интерфейс.

\- `tests/SmartParking.Tests/` — модульные тесты.

\- `docs/architecture/` — архитектурная документация и диаграммы.

\- `docs/openapi/` — спецификации OpenAPI.



\## Настройка Git



В репозитории используется `.gitignore`, исключающий:



\- каталоги сборки `bin/` и `obj/`;

\- служебные файлы Visual Studio;

\- локальные базы данных;

\- журналы;

\- временные файлы операционной системы.



Файл `.gitattributes` используется для нормализации текстовых файлов и определения бинарных форматов.



\## Git LFS



Для хранения крупных бинарных файлов настроен Git LFS.



Отслеживаются форматы:



```text

\*.bak

\*.zip

```



Настройка выполняется командами:



```bash

git lfs install

git lfs track "\*.bak"

git lfs track "\*.zip"

```



\## Проверка фильтрации



Для проверки `.gitignore` был создан тестовый файл:



```text

src/bin/Debug/test.dll

```



Команда:



```bash

git status

```



подтвердила, что каталог `bin` и находящийся в нем файл не добавляются в список отслеживаемых файлов.
